# 💰 Expense Tracker (React JS)

A simple and modern **Expense Tracker App** built using React JS.  
This project helps users track their daily expenses with a clean UI and real time total calculations.

---

## 🚀 Features

- ➕ Add new expense
- 🗑️ Delete expense
- 💰 Auto calculated total amount
- 💾 Data saved in Local Storage (persists after refresh)
- 🎨 Modern responsive UI with gradient background
- ⚡ Fast and lightweight (no backend)

---

## 🛠️ Tech Stack

- React JS (Vite)
- JavaScript (ES6+)
- CSS (Custom styling)
- LocalStorage APIs
